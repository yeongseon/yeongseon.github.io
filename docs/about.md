# About

I'm **Yeongseon Choe** — a developer who builds open-source tools and writes
about Azure, Python, and backend engineering.

Most of my public work right now centers on **developer experience for Azure
Functions in Python**: I maintain the [Azure Functions Python DX Toolkit](azure-functions-python/index.md),
a family of ten small, focused packages covering OpenAPI docs, request
validation, structured logging, pre-deploy diagnostics, scaffolding, and
AI/orchestration patterns.

I care about keeping tools small, staying close to the underlying platform, and
writing examples that reflect real production needs rather than hello-world.
