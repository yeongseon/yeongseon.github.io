# Projects

A running index of the open-source work I build and maintain. Most of it lives
under a single theme right now — developer experience for Azure Functions in
Python — and will broaden over time.

## Azure Functions Python DX Toolkit

A family of small, focused packages that fill the missing developer-experience
layer around Azure Functions Python. See the [toolkit landing page →](../azure-functions-python/index.md)
for how the pieces fit together.
